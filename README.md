## 说明

- 本仓库**仅供个人自用与学习交流**，不提供任何形式的支持与保证；请勿在生产环境或向他人分发。
- 主要的个人定制（截至 v1.2.4）：Windows 记忆窗口状态、镜像域名播放源解析与官方下载渠道、收藏页云端缓存先行与增量同步、搜索/推荐卡片按宽度自适应列数、新番预告纵向卡片、下载入队竞态修复等。
- 想使用持续维护的正式版本，请前往**上游原项目**。
